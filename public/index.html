      How it works

      A coin names a repo. Its vault fills from trading fees. Each commit spends the whole vault on the coin, then burns it.

      1. 1

        Pick a repo

        Paste any public GitHub repo. The coin is tied to it for good: its default branch becomes the trigger.

      2. 2

        Launch on Pons

        A standard Pons coin: bonding curve first, then a locked Uniswap v4 pool. Creator fees are split: % to the repo's buyback vault, % to Commit.

      3. 3

        Code ships, chart moves

        Our keeper watches the branch. A new commit lands, % of the vault buys the coin on its pool and the tokens go to the dead address. Every buy is on the chart.

      One rule, written down.

      No votes, no roadmap promises. The repo's commit history is the only input. If the code moves, the coin gets bought.

      • Only the default branch counts. Pushes to other branches do nothing.
      • A merge counts once. Force-pushed or rewritten commits never count.
      • A buy can only spend what the vault holds, so spamming commits never buys more than the fees that came in.
      • At most one buy every minutes per coin. Commits in between are batched.

      Questions

      Do the repo's maintainers have to do anything?

      No. Commit only reads public commit history. Maintainers don't sign up, hold anything or even know the coin exists. A coin doesn't mean they endorse it.

      What counts as a commit?

      A new commit that reaches the repo's default branch (usually main or master). A merged pull request counts once. Commits on other branches, and history that gets force-pushed away, don't count.

      What stops someone from spamming commits?

      A buy can only spend what's in the vault, and there's at most one buy every minutes per coin. Commits in between are batched into the next buy, so a hundred empty commits buy exactly what one would.

      Where do the fees go?

      % of each coin's creator fees fill its repo vault, which only buys back and burns that coin. % go to Commit.

      What if the repo goes quiet?

      No commits, no buys. The vault keeps what it has and spends it when the next commit lands.

      Which chain?

      Robinhood Chain. Coins launch through Pons, so they trade on Pons and on a locked Uniswap v4 pool after the curve.
